### 2.2. Оболочки колонны

Каждая колонна = **4 оболочки**, снимаются строго последовательно.

| Оболочка | Операция | Кубиков |
|----------|----------|---------|
| 1 (внешняя) | Сложение (+) | 60 |
| 2 | Вычитание (−) | 60 |
| 3 | Умножение (×) | 60 |
| 4 (внутренняя) | Деление (÷) | 60 |
| **Итого** | | **240** |

**Правило последовательности:**
- Пока оболочка 1 не убрана полностью (все 60 кубиков) — оболочка 2 неактивна.
- То же для оболочек 2 → 3 → 4.
- Стекло появляется только после полного снятия оболочки 4.

### 2.3. Геометрия оболочки

- Оболочка = **4 грани** × **15 кубиков** = **60 кубиков**.
- Грань = **3 кубика в ширину** × **5 слоёв в высоту** = 15.
- Колонна **вращается** свайпом влево/вправо.
- Игрок видит одну грань целиком, две под углом, четвёртую сзади.

### 2.4. Стекло и финал

- После снятия оболочки 4 — **голый стеклянный каркас**.
- За стеклом — **силуэт фигурки**.
- Игрок **кликает** по стеклу.
- Стекло **трескается**, **рассыпается** со звуком хруста.
- Фигурка **появляется** на подсвеченной подставке, вращается.
- Запускается **праздничный экран** (см. раздел 8).

## 3. МЕХАНИКА

### 3.1. Кубики

- **Число:** от 1 до 9 (точки, как на игральной кости).
- **Цвет:** 4 варианта (например, красный, синий, зелёный, жёлтый).
- Число и цвет **независимы**.

### 3.2. Уравнения (основная механика)

- Одно уравнение = **3 кубика**.
- 60 кубиков ÷ 3 = **20 уравнений** на оболочку.
- **Каждый кубик принадлежит ровно одному уравнению.** Коллизий нет.
- Операция оболочки фиксирована (+, −, ×, ÷).
- Игрок **нажимает** кубик-результат, затем два других.
- Если уравнение верное — три кубика **схлопываются** со звоном.
- Кубики **исчезают**, оставляя дыры. Дыры **не зарастают**.
- Уравнения собираются: внутри грани, через угол, по вертикали, через две грани.

**Примеры по оболочкам:**
- Оболочка 1: 3 + 5 = 8
- Оболочка 2: 9 − 4 = 5
- Оболочка 3: 3 × 2 = 6
- Оболочка 4: 8 ÷ 2 = 4

### 3.3. Тройка-в-ряд

**Условие:** три кубика совпадают **и по цвету, И по числу**.
- 🟢7 + 🟢7 + 🟢7 → ✅
- 🔵7 + 🔵7 + 🔴7 → ❌
- 🟢7 + 🟢7 + 🟢5 → ❌

**Алгоритм:**
1. Игрок собирает три кубика.
2. Система определяет, какие уравнения ломаются (осиротевшие кубики).
3. Система добирает осиротевшие кубики.
4. Если осиротевшие ломают другие уравнения — повторять шаг 3.
5. Каскад завершён, когда все оставшиеся кубики — в рабочих уравнениях.
6. Все кубики каскада схлопываются **по очереди** (волнами).
7. Бонус: **+2 хода** в банк.

**Правила:**
- Тройка **опциональна**. Оболочку можно завершить и без неё.
- **Запланированный каскад:** не более **12 кубиков** (генератор закладывает 1 тройку).
- **Случайный каскад:** если игрок находит тройку сам — каскад любой длины.
- Тройка **не считается** уравнением. Она убирает кубики дополнительно.

### 3.4. Каскад

- Запускается тройкой-в-ряд.
- Убирает тройку + осиротевшие кубики.
- Визуал: **по очереди**, волнами.
- Общее время каскада: 1,5–2,5 секунды.

### 3.5. Ходы

**Банк ходов на оболочку.** Не переносится между оболочками.

| Оболочка | Операция | Ходов |
|----------|----------|-------|
| 1 | + | 30 |
| 2 | − | 28 |
| 3 | × | 26 |
| 4 | ÷ | 24 |

**Стоимость действий:**
- Ошибка (неверное уравнение) = **−1 ход**
- Откат = **−1 ход**
- Тройка-в-ряд = **+2 хода**

**Если ходы кончились, а оболочка не пуста — оболочка сбрасывается.** Все 60 кубиков возвращаются. Ходы обнуляются до базовых для этой оболочки.

### 3.6. Комбо

- Счётчик комбо: 0, 1, 2, **3 → ×2**.
- Комбо **обнуляется** при ошибке.
- **Откат** — не ошибка. Комбо сохраняется.
- **Тройка-в-ряд** — не сбрасывает комбо.
- **Каскад** — сохраняет комбо.
- Множитель **×2** действует на все очки после 3-го уравнения подряд.

### 3.7. Ошибки и штрафы

- **Штрафов нет.** Только **−1 ход**.
- Ошибка обнуляет комбо.
- Откат доступен всегда, стоит 1 ход.

## 5. ГЕНЕРАТОР ОБОЛОЧКИ

### 5.1. Задача

60 кубиков, 20 уравнений, все кубики задействованы, одна операция.

### 5.2. Алгоритм

**Шаг 1. Определяем операцию** (фиксирована для оболочки).

**Шаг 2. Генерируем уравнения:**

- **Для «+»:** берём a, b так, чтобы a + b ≤ 9. c = a + b.
- **Для «−»:** берём a, c так, чтобы a > c. b = a − c ≥ 1.
- **Для «×»:** берём a, b так, чтобы a × b ≤ 9. c = a × b.
- **Для «÷»:** берём c, b так, чтобы c × b ≤ 9, b ≥ 2. a = c × b.

**Шаг 3. Раскладываем кубики на 4 грани:**

- 60 кубиков = 4 грани × 15.
- 60% уравнений — внутри грани.
- 25% — через угол (2 + 1).
- 15% — через две грани (1 + 1 + 1).
- Если позиций не хватает — перегенерировать.

**Шаг 4. Проверка разрешимости:**

- Каждый кубик — ровно в одном уравнении.
- Коллизий нет.
- Тупиков нет.
- Любой порядок решения работает.

**Шаг 5. Планирование тройки-в-ряд:**

- **1 запланированная** тройка (каскад до 12 кубиков).
- **0–1 случайная** тройка (каскад любой длины).
- Генератор **резервирует** кубики под тройку вне уравнений.
- Итог: **17–19 уравнений** + 1–3 тройки.

### 5.3. Мягкий старт

- **Верхние 2 слоя** (24 кубика) — простые числа (1–5).
- **Средний слой** (12 кубиков) — средние (1–7).
- **Нижние 2 слоя** (24 кубика) — сложные (1–9).

Игрок видит все 60 сразу, но интуитивно начинает сверху.

## 6. ТУТОРИАЛ

### 6.1. Общие правила

- **Обязателен** при первом запуске.
- Только **первый и второй слои** любой колонны.
- После прохождения — **не предлагается** автоматически.
- **Доступен** всегда через меню «Пройти обучение».

### 6.2. Часть 1. Формулы (1-й слой, 12 кубиков)

1. Игрок запускает игру впервые. Выбирает любую колонну.
2. Верхний слой подсвечивается.
3. Подсказка: «Нажми на кубик с числом 8» → кубик пульсирует.
4. «Теперь нажми на 3 и 5 — их сумма равна 8» → два кубика пульсируют.
5. Три кубика схлопываются. Звон. «Отлично! Ты собрал уравнение».
6. «Собери оставшиеся уравнения на слое». Игрок играет сам.
7. Слой пуст. «Слой разобран!»

### 6.3. Часть 2. Тройка-в-ряд (2-й слой, 12 кубиков)

8. Появляется второй слой. Среди кубиков заранее заложена тройка: 🟢7, 🟢7, 🟢7.
9. Подсказка: «Видишь три зелёных семёрки?» → три кубика пульсируют.
10. «Совпадают цвет И число — это тройка-в-ряд».
11. Игрок жмёт 🟢7 → 🟢7 → 🟢7.
12. Каскад: три семёрки + осиротевшие кубики схлопываются по очереди. Звон, бренчание, тряска.
13. «Каскад! Чем больше осиротевших — тем больше взрыв».
14. «+2 хода в банк».
15. «Тройки редки. Но они ускоряют игру и дают очки».
16. Туториал завершён. «Теперь ты знаешь всё. Играй!»

После этого — свободная игра. Оболочка продолжается как обычно.

## 8. СТИЛЬ

### 8.1. Мега-общий стиль

- **Материал:** стекло, металл, свет.
- **Форма:** колонна — цилиндр или гранёная призма. Кубики — скруглённые, объёмные.
- **Свет:** мягкий, тёплый фон. Колонна подсвечена изнутри.
- **Анимации:** плавные, пружинные.
- **UI:** минимализм. Полупрозрачные панели. Крупные кнопки. Читаемый шрифт.
- **Палитра:** глубокие тона (тёмно-синий, графит, бордо) + один акцентный цвет на колонну.
- **Звук:** один набор базовых звуков + вариации под колонну.

## 10. ПОЗДРАВЛЕНИЯ

### 10.1. После каждой колонны

Триггер: игрок убрал 4-ю оболочку, кликнул по стеклу, стекло рассыпалось, фигурка появилась.

**Сценарий (5–7 секунд):**
1. Краш стекла — хруст, осколки разлетаются.
2. Фигурка появляется на подсвеченной подставке. Вращается.
3. Фанфары (2–3 сек).
4. Конфетти падают сверху. Много. Разноцветное.
5. Салют — вспышки на фоне. Золото, серебро, цвет колонны.
6. Надпись крупно: «ПОЗДРАВЛЯЕМ!» / «CONGRATULATIONS!»
7. Под ней: название фигурки + счёт + время.
8. Кнопки: «Играть снова» / «В меню» / «В зал славы».

**Звук фанфар:** одна основа + вариация инструмента под стиль колонны.

### 10.2. После 10-й колонны

- Все 10 фигурок выстраиваются в ряд.
- Общий салют.
- Надпись: «ВСЯ КОЛЛЕКЦИЯ СОБРАНА» / «FULL COLLECTION».
- Кнопка «В меню».

## 15. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

- **Платформа:** Яндекс Игры (WebGL / Canvas).
- **Билд:** лёгкий, оптимизированный под браузер.
- **Адаптивность:** телефон, планшет, ноутбук, ПК.
- **Аккаунт:** Yandex Games SDK.
- **Сохранения:** `player.setData()` / `player.getData()` — автоматически.
- **Реклама:** только боковые плашки Яндекса. В игровое поле не встраивается.
- **Звук:** только после первого тапа игрока (требование Яндекса).
- **Локализация:** RU + EN, переключение на лету.
- **Игра финальная:** без обновлений контента. Только багфиксы.
